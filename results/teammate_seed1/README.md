# Teammate seed-1 evidence

This directory records the seed-1 result supplied by Hao Deng for the
additional-material report. The reported run used the repository's 100k
Dreamer V1 notebook with the training seed changed to 1.

Evidence level: teammate-reported aggregate summary. The raw `config.json`,
per-episode evaluation CSV, and checkpoint were not available in the local
workspace when this report was prepared. The value is therefore included as a
provisional comparison, not as independently verified raw evidence.

The attached summary was normalized into `summary_reported.json`; the SHA256
of the original supplied file is recorded there. It reports ten evaluation
episodes on environment seeds 1000--1009 for `cartpole_swingup`.
